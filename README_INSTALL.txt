2. Открыть папку проекта.
3. Проверить локально:
   npm install
   npm run dev
4. Открыть:
   http://localhost:3000
5. Войти:
   Danila / 000000
6. Загрузить содержимое проекта в GitHub.
7. Vercel подтянет обновление.
