Сайт МТФ Ясная Поляна v6.2

Что внутри:
- страница входа /
- главный экран /dashboard
- раздел Молоко /dashboard/milk

Вход:
Логин и пароль прежние, но подсказки в полях входа убраны.

Правильная установка:
1. В локальной папке репозитория удалить старые видимые файлы и папки, кроме скрытой папки .git.
2. Распаковать этот архив в папку репозитория.
3. Выполнить:
   git add -A
   git commit -m "Milk module v6.2"
   git push

Проверка локально:
npm install
npm run dev

Открыть:
http://localhost:3000
