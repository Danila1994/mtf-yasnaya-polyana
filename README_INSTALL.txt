Правильная установка:
1. Открыть локальную папку проекта, которая связана с GitHub.
2. Удалить все старые видимые файлы и папки, кроме скрытой папки .git.
3. Распаковать этот архив в эту папку.
4. Выполнить:
   git add -A
   git commit -m "Clean v6.1 site"
   git push

Если использовать GitHub Desktop:
1. Открыть репозиторий в GitHub Desktop.
2. В папке проекта удалить старые файлы, кроме .git.
3. Скопировать файлы из этого архива.
4. В GitHub Desktop нажать Commit to main.
5. Нажать Push origin.

Проверка локально:
npm install
npm run dev
