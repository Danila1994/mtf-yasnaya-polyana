Сайт МТФ Ясная Поляна v6.3.1

Главное изменение: добавлена вкладка Ввод данных.

Установка:
1. Удалить старые видимые файлы в папке репозитория, кроме .git.
2. Распаковать архив v6.3.1 в папку репозитория.
3. Выполнить:
   git add -A
   git commit -m "Milk module v6.3.1 data input"
   git push

Проверка:
npm install
npm run dev

Вход прежний, но подсказки в полях логина и пароля убраны.
