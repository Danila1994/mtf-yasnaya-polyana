Сайт МТФ Ясная Поляна v6.3.2.1

Главное изменение: добавлена вкладка Ввод данных.

Установка:
1. Удалить старые видимые файлы в папке репозитория, кроме .git.
2. Распаковать архив v6.3.2.1 в папку репозитория.
3. Выполнить:
   git add -A
   git commit -m "Milk module v6.3.2.1 data input"
   git push

Проверка:
npm install
npm run dev

Вход прежний, но подсказки в полях логина и пароля убраны.


Проверено: npm run build проходит успешно.


## Добавлено в v6.3.2

- базис молока по формуле: фактический кг × жир / 3.5;
- базис в дневном вводе, реализации, архивах и сводках;
- цена в реализации считается как цена за базисный кг;
- выручка считается по базису.

Формула базиса: базис = фактический кг * жир / 3.5.
