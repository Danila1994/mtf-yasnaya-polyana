# МТФ Ясная Поляна — v6.2

Чистая рабочая версия сайта.

## Вход

Логин и пароль сохранены в коде, но подсказки в полях входа убраны.

## Структура

- `/` — вход
- `/dashboard` — главный экран
- `/dashboard/milk` — раздел «Молоко»

## Молоко

Внутри раздела:

1. Обзор
2. Архив и статистика
3. Заводы и реализация
4. Прогноз

## Особенности v6.2

- убраны серые подсказки логина и пароля в форме входа;
- расширен модуль молока;
- добавлены несколько направлений реализации молока за один день;
- добавлен архив по месяцам;
- добавлена статистика;
- добавлена вкладка заводов и реализации;
- добавлена вкладка прогноза;
- добавлены графики без внешних библиотек;
- данные сохраняются локально в браузере через localStorage.
