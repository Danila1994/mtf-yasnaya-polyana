# МТФ Ясная Поляна — стартовая проверка сайта

## Запуск на ПК

1. Установите Node.js LTS.
2. Распакуйте архив.
3. Откройте папку проекта в PowerShell или терминале.
4. Выполните:

```bash
npm install
npm run dev
```

5. Откройте в браузере:

```text
http://localhost:3000
```

## Страницы

- `/` — стартовая страница
- `/login` — макет входа
- `/demo` — демо-отчет

## Статус

Это первая локальная проверка интерфейса. База данных, пользователи и роли будут подключаться следующим этапом.
