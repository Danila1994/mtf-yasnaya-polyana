# МТФ Ясная Поляна — v4 ежедневная сводка

Добавлена рабочая страница ежедневной сводки:

- `/dashboard/daily-summary`
- блок 1: молоко / количество голов
- блок 2: ветеринария / осеменение
- блок 3: зоотехния / расход кормов в день

Пока данные сохраняются локально в браузере через `localStorage`. Это тестовый режим без базы данных.
Следующий этап — подключение PostgreSQL/Supabase и настоящих пользователей.
