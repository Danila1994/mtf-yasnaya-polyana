# МТФ Ясная Поляна — тест входа v3

Версия 3 убирает зависимость от ввода логина/пароля на тестовом этапе.

## Проверка

1. Откройте `/login`.
2. Нажмите любую роль, например `Администратор`.
3. Должен открыться кабинет `/dashboard/admin`.
4. Разные роли должны видеть разные разделы.

Это тестовая логика без настоящей авторизации и базы данных.
